# Commit Messages

Always use the Conventional Commits format:

```
<type>[optional scope]: <description>

[optional body]

[optional footer(s)]
```

**Types:** `feat`, `fix`, `docs`, `style`, `refactor`, `perf`, `test`, `build`, `ci`, `chore`, `revert`

**Examples:**
- `feat(chat): add tool call display in message bubbles`
- `fix(documents): batch FGA writes with Promise.all`
- `perf(auth): add React.cache() for session deduplication`
- `chore: update model name to gpt-5-mini`
